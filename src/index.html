01 · البداية

ابدأ هنا

أربع خطوات من مساحة فارغة إلى ملف جاهز للاستخدام.

  1. افتح المحرر

    اختر مخطط Hybrid أو Generator backup أو Solar pump من Starting layout، أو ابدأ من Blank canvas.

  2. رتّب واربط

    اسحب العناصر أو صورك إلى المساحة. اضغط Connect (أو حرف C) ثم العنصر المصدر والهدف.

  3. أدخل بيانات العرض

    اختر العنصر لتعديل الاسم والقيمة والوحدة والتيار والكفاءة ونص الحالة من تبويب Data.

  4. احفظ وصدّر

    Save project يحفظ ملف .flow.json قابلًا لإعادة الفتح. Export ينتج ملفات العرض والكود.

i

الحقول تعرض القيم التي ترسلها؛ لا ينفّذ المحرر محاكاة للطاقة. حالات العناصر والخطوط مستقلة أيضًا: إخفاء عنصر لا يخفي خطوطه.

دليل المحرر

لوحة الخصائص مقسّمة إلى تبويبات. اختر عنصرًا أو خطًا لتظهر إعداداته.

العناصر الجاهزة

مكتبة Elements تضم: صفوف ألواح (Solar array)، لوح منفرد، منزل بألواح على السطح (Solar home)، مدرسة بفناء ومظلة ألواح (School)، مصنع بسطح ألواح (Factory)، البطارية، الإنفرتر، برج الشبكة، عمود كهرباء بمحوّل (Utility pole)، الحمل، مولد الديزل، المضخة، ونقطة التقاء. كلها رسومات متناسقة بخلفية شفافة. جرّب Starting layout: Solar home system أو School solar system أو Factory with generator backup.

منزل بأجزاء قابلة للإضافة

العنصران Villa + parts (فيلا حديثة: ألواح السطح، إنفرتر وعدّاد على الحائط، وبطارية) وHouse + parts منزل له أماكن ثابتة: السطح للألواح، الحائط للإنفرتر، والفناء للبطارية ولعمود الكهرباء. اختر المنزل ثم تبويب Parts وفعّل أو ألغِ كل جزء. كل جزء عنصر مستقل له معرّف وقيم وحالة يمكن تحديثها من تطبيقك، ويتحرك ويكبر مع المنزل. الخطوط بين الأجزاء تُضاف تلقائيًا وتُرسم فوق المنزل (خيار onTop). حجم كل جزء من Layout → Size. جرّب Starting layout → Modern villa أو Home with roof solar & yard parts. المشهد Cloudy يعطي سماء غائمة ناعمة.

على الويب، أو داخل Next.js وVue

صدّر من Export → HTML، ضع الملف في مجلد الملفات الثابتة، واعرضه في iframe.

في Next.js أو Vue مع Vite ضع الملف مثلًا في public/flows/hybrid.html. في موقع HTML عادي استخدم رابط الملف الذي رفعته.

HTML · embed
<iframe
  id="energy-flow"
  src="/flows/hybrid.html"
  title="Energy flow"
  style="width:100%;aspect-ratio:1000/650;border:0"
></iframe>

بعد تحميل الملف، استدعِ واجهة التحكم من الصفحة الأم:

JavaScript · live data
const frame = document.getElementById('energy-flow');

frame.addEventListener('load', () => {
  const flow = frame.contentWindow.energyFlow;

  flow.setNodeData('inverter', {
    name: 'الإنفرتر الرئيسي',
    value: 5.2,
    unit: 'kW',
    current: 23.6,
    currentUnit: 'A',
    efficiency: 96.8,
    status: 'يعمل',
    showDetails: true
  });

  flow.setNodeState('inverter', 'active');
  flow.setFlowState('solar', 'active');
});
!
نفس الـ origin.

الوصول إلى contentWindow يتطلب أن تكون الصفحة وملف الفلو من نفس النطاق. في Next.js نفّذ الكود في جانب المتصفح؛ وفي Vue بعد تحميل العنصر.

04 · الدمج

Flutter على Android وiOS

مكتبة flow_studio ترسم المخطط داخل التطبيق مباشرة، بنفس المسارات والحركة والصور والتسميات.

  1. صدّر

    من المحرر اختر Export → Flutter (native). يُحفظ ملف المشروع ويظهر كود Dart كامل بأسماء عناصرك.

  2. أضف الملف والمكتبة

    ضع الملف في assets وأضفهما إلى pubspec.yaml.

  3. الصق الكود وحدّث القيم

    نفس أوامر HTML: الحالات، القيم، الاتجاه، الإيقاف والتشغيل.

pubspec.yaml
dependencies:
  flow_studio:
    path: ../flow_studio  # packages/flow_studio from this project

flutter:
  assets:
    - assets/hybrid.flow.json
Dart · native widget
import 'package:flow_studio/flow_studio.dart';

// 1. Load the exported project.
final flow = FlowController.asset('assets/hybrid.flow.json');

// 2. Show it — keeps the canvas aspect ratio.
FlowStudioView(
  controller: flow,
  onNodeTap: (node) => print(node.id),
)

// 3. Update live data at any time.
flow.setNodeData('inverter',
  name: 'الإنفرتر الرئيسي',
  value: 5.2,
  unit: 'kW',
  current: 23.6,
  efficiency: 96.8,
  status: 'يعمل',
  showDetails: true,
);
flow.setNodeState('grid', FlowState.inactive);
flow.setFlowState('grid', FlowState.hidden);
flow.setFlowDirection('battery', -1);
flow.pause(); // flow.play();

// Or several values at once (same shape as the HTML event):
flow.applyData({
  'nodes': {'solar': {'value': 8.7, 'unit': 'kW'}},
  'flows': {'solar': 'active', 'grid': 'inactive'},
});
✓
مطابقة التصميم.

المسارات مطابقة لمحرك المحرر حرفيًا، والفرق مع صورة PNG المصدَّرة أقل من 0.3% من البكسلات (حواف الحروف فقط). على Android ضمّن خط Arial أو Arimo مع خط عربي ومرّره عبر FlowTextStyle.

إذا كنت تفضّل ملف HTML المصدَّر، اعرضه بـ webview_flutter وأرسل البيانات بـ runJavaScript:

Dart · WebView
// flutter pub add webview_flutter
final controller = WebViewController()
  ..setJavaScriptMode(JavaScriptMode.unrestricted)
  ..loadFlutterAsset('assets/flows/hybrid.html');

// After the page finishes loading:
controller.runJavaScript(
  "energyFlow.setNodeData('inverter', ${jsonEncode({'value': 5.2})});",
);

WebViewWidget(controller: controller)

05 · المرجع

البيانات، الأسماء، والحالات

status هو نص الحالة المعروض مثل «يعمل». أما حالة الظهور فتُرسل إلى setNodeState أو setFlowState.

active

العنصر ظاهر بالكامل، والخط يتحرك.

inactive

العنصر باهت، والخط ظاهر بدون حركة.

hidden

مخفي بالكامل.

JavaScript · controls
energyFlow.setNodeState('battery', 'inactive');
energyFlow.setFlowState('grid', 'hidden');

// 1: source → target | -1: target → source
energyFlow.setFlowDirection('battery', -1);

energyFlow.pause();
energyFlow.play();

// Dashboard: battery level, status badge, lit windows
energyFlow.setNodeData('battery', { soc: 48, badge: 'Charging', badgeTone: 'green' });
energyFlow.setNodeData('home', { lit: true });
energyFlow.setFlowColor('grid', '#f2a541', '#f6dcb4');
energyFlow.setHeader({ status: 'Online', weather: 'sun', temperature: '29°C', updated: 'Last update 12:40' });
energyFlow.setScene('night');   // none | day | dusk | night | rain
energyFlow.setTheme('dark');    // light | dark

// Read IDs, positions, values and states
const project = energyFlow.getProject();
