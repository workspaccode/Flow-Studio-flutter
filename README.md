# Flow Studio

محرر فلو للطاقة يعمل مباشرة من ملفات HTML، باستخدام مجسمات Solar / Battery / Inverter / Grid / Home الموجودة في ملفاتك السابقة، ونفس أسلوب الخطوط الفاتحة ذات الزوايا الدائرية والحركة الزرقاء.

## الشاشات الجديدة

- **Loading**: تظهر أثناء فك صور المجسمات المضمّنة، وتعرض تقدمًا فعليًا وحالة نجاح أو خطأ مع إعادة المحاولة.
- **Landing**: صفحة تعريف عربية بمعاينة متحركة داخل نافذة تطبيق، وقيم تتحدّث كل ثانيتين لعرض البيانات الحية، ومزايا المحرر، والخطوات، ومثال كود بتبويبي Dart وJavaScript، والمنصات.
- **Docs**: قائمة جانبية مجمّعة مع بحث وتظليل القسم الحالي أثناء التمرير، بطاقات وصول سريع، ودليل المحرر (خيارات الخطوط، صيغ الصور، الاختصارات)، والويب، وFlutter (المكتبة أو WebView في تبويبين)، والبيانات والحالات، وصيغ التصدير.

يفتح المشروع على صفحة التعريف بعد اكتمال التحميل. انتقل من الأزرار العلوية، أو افتح أحد الروابط داخل نفس الملف:

| الرابط | الشاشة |
| --- | --- |
| `#home` | صفحة التعريف |
| `#editor` | المحرر |
| `#docs` | دليل الاستخدام |
| `#docs/editor` | دليل المحرر |
| `#docs/web` | التضمين على الويب |
| `#docs/flutter` | Flutter |
| `#docs/api` | القيم والأسماء والحالات |
| `#docs/exports` | صيغ التصدير |
| `#loading` | شاشة التحميل بعد اكتمال التجهيز |

التنقّل لا يعيد تحميل المشروع ولا يغيّر بياناته. جدول المعرّفات داخل التوثيق يعرض عناصر وخطوط المخطط الحالي. أمثلة `energyFlow` تخص HTML الناتج من **Export → HTML**؛ أما واجهة المحرر فهي `flowStudio`. ملف الرسم المصدَّر يحتوي على الفلو وواجهة التحكم فقط.

## تشغيل سريع

1. افتح `Flow-Studio.html` الموجود في جذر المشروع في Chrome أو Edge أو Safari أو Firefox حديث.
2. اختر مخطط Hybrid أو Generator backup أو Solar pump أو Blank canvas.
3. أضف العناصر من القائمة، واسحبها على مساحة الرسم.
4. اضغط **Connect** ثم العنصر المصدر والعنصر الهدف.
5. اضغط على عنصر أو خط لتعديل الخصائص.
6. اضغط **Save project** للاحتفاظ بنسخة قابلة للتحرير، أو **Export** لاستخراج النتيجة.

لا يحتاج المحرر إلى إنترنت أو npm أو سيرفر. النسخة المقسّمة في `src/index.html` تعمل أيضًا مباشرة. لحفظ الملفات من هاتف أو تابلت قد تحتاج إلى فتح الملف في متصفح كامل بدلًا من معاينة تطبيق الملفات.

## العناصر الجاهزة

صفوف ألواح شمسية، لوح منفرد، منزل بألواح على السطح، مدرسة بفناء ومظلة ألواح، مصنع بسطح ألواح وخزانات، بطارية، إنفرتر، برج شبكة، عمود كهرباء بمحوّل، حمل منزلي، مولد ديزل، مضخة، ونقطة التقاء. الرسومات الجديدة مرسومة برمجيًا بنفس الأسلوب (منظور أيزومتري، إضاءة وظلال ناعمة)، بخلفية شفافة وصيغة WebP. مخططات جاهزة: Solar home system، School solar system، Factory with generator backup.

### شكل لوحة المتابعة (Dashboard)

- **تسميات بخط إرشادي (Callout):** القيمة بجانب العنصر مع خط منقّط يصل إليه، تُسحب على المساحة، وزر **Dashboard labels** يرتّبها في عمودين حول المنزل.
- **مستوى البطارية (SOC):** النسبة بجوار الاسم وشريط ملوّن (أخضر/برتقالي/أحمر).
- **شارة الحالة:** Charging أو Standby أو Importing… بخمسة ألوان.
- **إضاءة النوافذ (lit):** للعناصر التي لها طبقة إضاءة.
- **بلاطة أيزومترية (tile)** تحت أي عنصر.
- **سمة فاتحة أو داكنة، ومشهد** نهار/غروب/ليل/مطر متحرك، و**شريط علوي** بالحالة والطقس والحرارة وآخر تحديث.
- **ألوان خطوط جاهزة حسب المعنى** (شمسي، شحن، استيراد، تصدير، خامل).

كلها حقول اختيارية في الملف (`callout`، `soc`، `badge`، `lit`، `tile`، `theme`، `scene`، `header`)، ومدعومة في HTML وSVG وPNG ومكتبة Flutter. من الكود:

```js
energyFlow.setNodeData('battery', { soc: 48, badge: 'Charging', badgeTone: 'green' });
energyFlow.setFlowColor('grid', '#f2a541');
energyFlow.setHeader({ status: 'Online', weather: 'sun', temperature: '29°C' });
energyFlow.setScene('night'); energyFlow.setTheme('dark');
```

### منزل بأجزاء قابلة للإضافة

العنصر **House + parts** له أماكن جاهزة: السطح (ألواح)، الحائط (إنفرتر)، الفناء (بطارية، وعمود كهرباء). من تبويب **Parts** تضيف أو تحذف كل جزء بضغطة. كل جزء عنصر عادي بمعرّف وبيانات وحالة خاصة به ومحفوظ في الملف بالحقل `attach: {to, slot}`؛ يتحرك ويكبر مع المنزل، وسحبه يحرّك المنزل كله، وحذف المنزل يحذف أجزاءه، والتكرار ينسخها مع خطوطها. الخطوط بين الأجزاء (ألواح → إنفرتر → بطارية / عمود) تُنشأ تلقائيًا وتُرسم فوق العناصر (`onTop: true`)، وهذا مدعوم أيضًا في SVG وPNG ومكتبة Flutter.

### الفيلا الحديثة

**Villa + parts**: فيلا بيضاء بسقف مسطح وتراس زجاجي، وأجزاء منفصلة: ألواح السطح، الإنفرتر وعدّاد الشبكة على الحائط، والبطارية أمام المنزل. كل جزء عنصر مستقل بحجم قابل للتحكم، وخط الشبكة ينزل من العدّاد إلى الأرض. المخطط الجاهز **Modern villa** يطابق شكل تطبيقات المراقبة: مشهد غائم (`scene: "cloudy"`)، شريط علوي بالحرارة، وتسميات بخط إرشادي.

### حجم الأجزاء

اختر الجزء (مثل الإنفرتر على الحائط) ثم **Layout → Size**: من 50٪ إلى 250٪. أجزاء الحائط تكبر حول منتصفها، والبطارية والعمود يكبران من قاعدتهما للأعلى، وخطوط الكابلات تتبع الحجم الجديد. يُحفظ في الملف كـ `attach.scale`.

## عارض الملفات Flow Viewer

`Flow-Viewer.html` صفحة مستقلة بهوية Flow Studio لعرض ملفات `.flow.json`: افتح عدة ملفات أو اسحبها، تنقّل بينها بالأسهم، وضع عرض بملء الشاشة (F)، تنقّل تلقائي كشرائح، بيانات تجريبية حية، تغيير السمة والمشهد للعرض فقط، وحفظ صورة PNG. يعمل بدون إنترنت، والملفات لا تغادر الجهاز.

## ماذا تستطيع التحكم فيه؟

- اسم كل عنصر، القيمة، الوحدة، التيار ووحدته، الكفاءة، ونص الحالة.
- `active`: العنصر واضح، والخط يتحرك.
- `inactive`: العنصر باهت، والخط الأساسي ظاهر بدون حركة.
- `hidden`: العنصر أو الخط مخفي بالكامل.
- حالات العناصر والخطوط مستقلة؛ إخفاء عنصر لا يغير حالة الخطوط المتصلة به.
- موقع العنصر وأبعاده، موقع التسميات، حجم النص ولونه.
- لون الخط الأساسي ولون الحركة، العرض، اتجاه الحركة، مدة الدورة، واستدارة الزوايا.
- الربط من أي اتجاه: اختر العنصر واسحب من إحدى نقاطه الأربع (أعلى، أسفل، يمين، يسار) إلى جانب العنصر الهدف، أو انقر النقطة ثم الهدف. اسحب طرف أي خط محدد لإعادة ربطه بجانب أو عنصر آخر. أداة Connect تستخدم الجانب الأقرب لمكان النقر.
- شكل الخط: مستقيم، متعرّج بزوايا قائمة (Elbow)، أو منحنى ناعم، من تبويب Route أو من الشريط العائم الذي يظهر فوق الخط المحدد (مع زر Auto لإعادة المسار التلقائي وزر عكس الاتجاه).
- التحكم في كل جزء: في الخط المتعرّج اسحب مقبض أي جزء لتحريكه وتبقى الزوايا قائمة (تُضاف زاوية جديدة تلقائيًا عند الحاجة). في المستقيم والمنحنى اسحب كل زاوية بحرية.
- مكان الربط: اسحب طرف الخط إلى أي نقطة على جانب العنصر فيرتبط هناك بالضبط (يُحفظ كإزاحة على الجانب)، ويرجع لمنتصف الجانب عند الاقتراب منه. نقطة البداية والنهاية على أي جانب مع إزاحة على طول الجانب.
- عدد النبضات المتحركة (1–12)، طول النبضة، قوة التوهج، ونمط الخط الأساسي: متصل أو متقطع أو نقاط.
- مسارات تلقائية أو نقاط تحكم يدوية: انقر مرتين على الخط لإضافة نقطة، ومرتين على النقطة لحذفها، أو اكتب إحداثياتها.
- استيراد الصور بالسحب والإفلات أو اللصق أو الاختيار، وعدة صور مرة واحدة: SVG وPNG وJPEG وWebP تُحفظ كما هي دون إعادة ضغط. GIF وAVIF وBMP وICO (وTIFF/HEIC في Safari) تُحوَّل إلى PNG بدون فقد وبدقتها الكاملة. يحتفظ استيراد SVG بالـ CSS الآمن الداخلي؛ الموارد الخارجية يجب تضمينها أولًا.
- تبويب Layout يعرض دقة الصورة ويحذّر إذا كانت غير كافية لتصدير 3×، مع استبدال الصورة وضبط النسبة.
- التراجع والإعادة، تكبير مساحة الرسم، شبكية المحاذاة، وحفظ مسودة محلية.

الحقول تعرض البيانات فقط. لا توجد محاكاة للطاقة ولا تعديل لمحاكاة ملفاتك السابقة.

## صيغ التصدير

| الصيغة | المحتوى |
| --- | --- |
| `.html` | مخطط متحرك مستقل، الأصول مضمّنة، وواجهة JavaScript لتحديث البيانات والحالات |
| `.svg` | مسارات متجهية متحركة، صور مضمّنة، وتسميات نصية قابلة للتحرير |
| `.png` | لقطة ثابتة عند الوقت المحدد، بدقة 1× أو 2× أو 3×، مع خيار خلفية شفافة |
| `.flow.json` | ملف المشروع القابل لإعادة الفتح والتحرير، بما فيه الأصول المستخدمة |
| Flutter | ملف `.flow.json` مع كود Dart كامل جاهز لمكتبة `flow_studio` (رسم أصلي بدون WebView) |

تستخدم الشاشة وSVG وPNG وFlutter إحداثيات Bézier نفسها. يمنع التصدير إذا خرج المحتوى خارج مساحة الرسم؛ استخدم **Canvas settings → Fit canvas to content** لضبطها.



SVG يستخدم Arial مع بديل sans-serif؛ قد تختلف قياسات الخط قليلًا بين أنظمة التشغيل. PNG يُرسم على الجهاز الذي ينفّذ التصدير.

## التحكم من JavaScript في HTML المُصدَّر

```js
// active | inactive | hidden
energyFlow.setNodeState('solar', 'active');
energyFlow.setFlowState('grid', 'hidden');

energyFlow.setNodeData('solar', {
  name: 'الطاقة الشمسية',
  value: 8.7,
  unit: 'kW',
  current: 12.4,
  currentUnit: 'A',
  efficiency: 96.8,
  status: 'يعمل',
  showDetails: true
});

// 1 = source → target; -1 = target → source
energyFlow.setFlowDirection('battery', -1);
energyFlow.pause();
energyFlow.play();

// Compatibility aliases from the previous discussion:
setNodeState('battery', 'inactive');
setFlowState('battery', 'active');
```

أو إرسال تحديث بيانات:

```js
window.dispatchEvent(new CustomEvent('energy-flow-data', {
  detail: {
    nodes: { solar: { value: 8.7, unit: 'kW' } },
    flows: { solar: 'active', grid: 'inactive' }
  }
}));
```

المعرّفات تظهر تحت عنوان الخصائص عند اختيار العنصر أو الخط. العناصر الافتراضية: `solar`, `battery`, `inverter`, `grid`, `home`, `junction`. في مخطط المولد، يبقى معرّف عنصر الاحتياط `grid` للتوافق بينما نوعه `generator`.

## Flutter بدون WebView

مكتبة `packages/flow_studio` ترسم ملف `.flow.json` داخل Flutter مباشرة: نفس المسارات والانحناءات وحركة الخطوط والصور والتسميات والحالات. من المحرر اختر **Export → Flutter (native)**، ضع الملف في `assets`، والصق الكود الذي يظهر:

```dart
final flow = FlowController.asset('assets/hybrid.flow.json');

FlowStudioView(controller: flow);

flow.setNodeData('solar', value: 8.7, status: 'يعمل');
flow.setFlowState('grid', FlowState.hidden);
```

التفاصيل والمثال الكامل في [packages/flow_studio/README.md](packages/flow_studio/README.md).

**مزامنة المحرك:** منطق المسارات في `packages/flow_studio/lib/src/geometry.dart` منقول من `src/core.js`. بعد تعديل `points` أو `geometry` في core.js، عدّل ملف Dart بنفس الطريقة، ثم شغّل:

```sh
cd packages/flow_studio
node tool/geometry_fixtures.js   # يولّد المسارات المتوقعة من core.js
flutter test                     # يقارن كل خط حرفيًا + مقارنة بكسل مع PNG المصدَّر
```

## دمجه داخل Next.js أو Vue

ضع ملف HTML المُصدَّر في مجلد الملفات الثابتة للمشروع واعرضه في iframe. لا يعتمد محرك الفلو على React أو Vue:

```html
<iframe
  src="/hybrid-energy-flow.html"
  title="Energy flow"
  style="width:100%;aspect-ratio:1000/650;border:0"
></iframe>
```

إذا كان الملف من نفس origin، يمكن استدعاء `iframe.contentWindow.energyFlow` بعد حدث `load`. للوصول المباشر من مكوناتك، يمكن تحميل `core.js` واستخدام `FlowCore.render(project)` بدلًا من iframe؛ استدعاء الدوال يكون في المتصفح.

## تقسيم المصدر

- `src/index.html`: واجهة المحرر.
- `src/styles.css`: تصميم المحرر والاستجابة للموبايل.
- `src/screens.css`: تصميم شاشات Loading وLanding وDocs.
- `src/screens.js`: التنقّل، تحميل الصور، معاينة الفلو، ونسخ أمثلة التوثيق.
- `src/core.js`: النموذج، مسارات Bézier، الرسم والتصدير.
- `src/app.js`: السحب، لوحة الخصائص، التراجع، الحفظ والاستيراد.
- `src/assets.json`: الأصول المستخدمة.
- `src/assets-data.js`: الأصول وكود المحرك المضمّن لتصدير HTML دون شبكة.
- `src/build.py`: تجميع المحرر Flow-Studio.html والعارض Flow-Viewer.html.
- `src/viewer.html` و`viewer.js` و`viewer.css`: عارض الملفات.
- `examples/`: ملفات مُصدَّرة جاهزة من المخطط الافتراضي.

بعد تعديل المصدر، شغّل:

```sh
python src/build.py
```

ينشئ `Flow-Studio.html` في جذر المشروع ويحدّث `assets-data.js`. لا توجد مكتبات JavaScript لازمة للتشغيل.

## ملاحظات الحفظ

الحفظ المحلي مسودة على هذا الجهاز والمتصفح فقط. **Save project** هو النسخة التي يمكنك نقلها أو الاحتفاظ بها. **Open project** يقبل `.flow.json` فقط.

حدود العمل: 100 عنصر، 200 خط، 80 نقطة يدوية لكل خط، ومساحة حتى 4096 × 4096. ملفات المشاريع حتى 100 MB، وصور الاستيراد حتى 40 MB و10000 × 10000 بكسل. يعمل المحرر باللمس؛ استخدم التكبير والتحريك على المساحة الفارغة لترتيب العناصر الدقيقة.
